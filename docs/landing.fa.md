# لندینگ تعاملی AiDirect

مسیر `/`، جدا از ورود `/sendbox`، مطابق انتخاب سوم کاربر و اصلاح بعدی ساخته شد. طرح با Product Design و ImageGen کاوش شد؛ خروجی تصویری فقط مرجع طراحی است و به‌جای UI در صفحه قرار نگرفته است.

## طراحی و منابع

- پس‌زمینه #10110f، متن #f5f2e8، زرد #f4df59؛ فونت محلی Estedad Variable نسخهٔ 5.3.0 با وزن 100 تا 900، بستهٔ دارای OFL-1.1. [منبع فونت](https://github.com/aminabedi68/Estedad).
- آیکون‌های Phosphor React نسخهٔ 2.1.10، مجوز MIT؛ import مستقیم در بخش تعاملی. [منبع آیکون‌ها](https://github.com/phosphor-icons/react).
- صفحهٔ معرفی Server Component است و تنها نمونهٔ گفتگو Client Component؛ CSS Modules از نشت استایل به ورود جلوگیری می‌کند. هیچ سرویس انیمیشن، ردیابی یا API خارجی برای لندینگ اضافه نشده است.

## رفتار نمونه

کاربر کامنت و کلمهٔ محرک را تغییر می‌دهد، «امتحان کن» را می‌زند و نتیجهٔ تطبیق را می‌بیند. تابع تطبیق همان تابع خالص برنامه است: فارسی/عربی ی و ک، فاصله‌ها و مرز کامل کلمه. «قیمتش» با «قیمت» منطبق نیست. پاسخ نمایشی از قبل ثابت است؛ این نمونه تنظیم قانون واقعی نیست.

نمونه هیچ fetch، فرم ارسالی، storage یا ثبت داده ندارد. لینک محصول نمونه صرفاً متن است. نتیجهٔ اولیه منطبق برای نمایش مسیر است؛ تغییر هر ورودی آن را به حالت آمادهٔ بررسی برمی‌گرداند. تا پایان نمایش کوتاه بررسی، ورودی‌ها و ارسال دوباره قفل می‌شوند؛ timer هنگام خروج پاک می‌شود.

حرکت‌ها: ورود یک‌بارهٔ دو خط تیتر، پیشرفت بررسی و ظاهرشدن پاسخ، hover دکمه؛ حلقهٔ دائمی ندارد. `prefers-reduced-motion` حرکت‌ها، smooth scroll و تأخیر نمایشی را حذف می‌کند. نتیجه `role=status` دارد؛ کنترل‌ها label، focus واضح و دسترسی کیبورد دارند.

## حدود واقعی

ورود و اتصال پیج همان مسیر امن موجود است. نمونهٔ متحرک اثبات اتصال یا ارسال خصوصی واقعی نیست. پیام نسخهٔ آزمایشی و غیرفعال‌بودن ارسال در لندینگ دیده می‌شود؛ قابلیت چندمشتری، ثبت‌نام عمومی، پرداخت یا AI اضافه نشده است. گزارش مقایسهٔ بصری در [design-qa.md](../design-qa.md) است.

متن نهایی دستور طراحی ImageGen: اصلاح طرح سوم، حفظ تیتر «از «لینک» تا یک گفتگوی تازه.» و پالت دارک/زرد؛ حذف مدار، نور و نقل‌قول تزئینی؛ جایگزینی با میز کار تعاملی سه‌بخشی برای کامنت، کلمه و پاسخ نمونه؛ فونت فارسی سنگین، فضای خالی و مرزهای ظریف؛ بدون عکس، آمار مشتری، قیمت یا وعدهٔ ارسال واقعی. ابزار داخلی ImageGen استفاده شد، بدون خرید API تصویری.
