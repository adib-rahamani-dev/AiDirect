# کاتالوگ و مسیر توسعهٔ فروش

درخواست جدید مالک، کاتالوگ، پیشنهاد بودجه، چندپیج، CRM و پرداخت را به دامنهٔ محصول اضافه کرد. این قابلیت‌ها مرحله‌ای ساخته می‌شوند. این صفحه وضعیت واقعی همین نسخه را از کارهای باقی‌مانده جدا می‌کند.

## همین حالا قابل استفاده

- `/admin/catalog`: تعریف چند پیجِ کاتالوگ، محصول، توضیحات، دسته‌بندی، قیمت صحیح به تومان، موجودی، فعال/غیرفعال و لینک HTTPS؛ ویرایش و حذف محصول.
- نسبت‌دادن یک یا چند محصول به لینک پست/ریلز، با برچسب ارتباط دستی. این کار **مالکیت پست یا اتصال Instagram را تأیید نمی‌کند**.
- تست پیشنهاد از کاتالوگ همان پیج و workspace؛ حداکثر سه محصول فعال، موجود و داخل سقف بودجه، با ترتیب قیمت صعودی. محدودکردن پیشنهاد به پستِ ثبت‌شده از API نیز ممکن است. دسته‌بندی در فرم صریح انتخاب می‌شود؛ موتور قواعد فهم آزاد همهٔ جملات نیست.
- ارقام فارسی/عربی، «هزار» و «میلیون» پشتیبانی می‌شوند. «۳۰ تومن» بدون زمینه نیازمند تأیید است؛ «۳۰ میلیون تومان» یعنی ۳۰٬۰۰۰٬۰۰۰ تومان. مبلغ ریالی، چند مبلغ یا بازهٔ مبهم حدس زده نمی‌شود.
- CSV کاتالوگ و فیلتر/CSV گزارش مسیر آزمایشی مدیر. متن پیام‌ها و توکن‌ها در CSV گزارش نیستند. فایل گزارش حداکثر ۱۰۰۰ ردیف دارد.
- توقف پیشنهادهای workspace، حذف کامل کاتالوگ با تأیید، و توقف اضطراری worker مسیر proof. درخواست خارجی که قبلاً شروع شده قابل پس‌گرفتن نیست.
- هشدار انقضای اتصال و تازگی heartbeat داخل پنل عملیات؛ ایمیل، پیامک و پایش دائمی فعال نشده‌اند.

قیمت با BIGINT و قید مثبت/سقف در PostgreSQL نگهداری می‌شود. `User / Workspace / Membership` و نقش‌های OWNER/EDITOR/VIEWER ساخته شده‌اند. تمام عملیات کاتالوگ membership را سمت سرور می‌سنجند؛ قیدهای خارجی مرکب، پیوند محصول یا پست به workspace/پیج دیگر را در دیتابیس هم رد می‌کنند. **ورود عمومی مشتری و مدیریت دعوت اعضا هنوز ساخته نشده است**؛ دسترسی فعلی با ورود مدیر و workspace داخلی اوست. مدل‌های قدیمی اتصال/صف/گزارش همچنان proof تک‌مدیرند و به مشتری‌ها ارائه نمی‌شوند.

## API رایگان برای تست AI

گزینهٔ بررسی‌شده: [Groq Free Plan](https://console.groq.com/docs/rate-limits). در بررسی ۱۸ اکتبر ۲۰۲۶، `openai/gpt-oss-20b` در جدول رایگان با ۳۰ درخواست/دقیقه، ۱۰۰۰ درخواست/روز، ۸۰۰۰ توکن/دقیقه و ۲۰۰هزار توکن/روز بود. سهمیهٔ واقعی را از Console خود حساب بخوان؛ رایگان‌بودن تضمین همیشگی نیست.

1. در [Groq Console](https://console.groq.com/) با حساب واجد شرایط خودت وارد شو. برنامه هیچ اشتراک یا روش پرداختی اضافه نمی‌کند.
2. قبل از ساخت کلید، امکان استفاده با کشور/هویت/کسب‌وکارت و [شرایط سرویس، بند ۶.۳](https://console.groq.com/docs/legal/services-agreement) را بررسی کن. صرف وجود پلن رایگان به معنی مجازبودن دسترسی از همهٔ کشورها نیست. صلاحیت حساب فعلی تأیید نشده است.
3. در [API Keys](https://console.groq.com/keys)، کلید بساز و فقط در فایل خصوصی `.env` مقابل `GROQ_API_KEY` قرار بده؛ در چت یا Git ننویس.
4. برای تست ثابت ساختگی، `GROQ_SYNTHETIC_TEST_ENABLED=true` و `npm run ai:test` را اجرا کن. این فرمان فقط یک درخواست نمونه دربارهٔ لپ‌تاپ می‌فرستد؛ مشتری واقعی، شناسهٔ اینستاگرام، موجودی و قیمت‌های فروشگاه فرستاده نمی‌شوند.
5. موفقیت: خروجی `synthetic_external_api_test`، دسته‌بندی معتبر و بودجهٔ ۳۰میلیون؛ این خروجی **ارسال دایرکت نیست**. فعلاً کلیدی موجود نیست و درخواست واقعی Groq انجام نشده؛ آزمون adapter با پاسخ ساختگی موفق است.

adapter فقط دسته‌بندی از فهرست مجاز استخراج می‌کند؛ اجازهٔ ساخت محصول/قیمت/URL یا تغییر بودجه ندارد، خروجی با Zod کنترل می‌شود و redirect، retry و fallback پولی ندارد. خاموش یا خراب‌بودن آن موتور قواعد رایگان کاتالوگ را مختل نمی‌کند. [endpoint رسمی](https://console.groq.com/docs/openai)، [JSON و اعتبارسنجی](https://console.groq.com/docs/structured-outputs)، [حفظ داده و ZDR](https://console.groq.com/docs/your-data) بررسی شدند. این adapter به webhook یا worker وصل نشده است.

Gemini هم [سطح رایگان](https://ai.google.dev/gemini-api/docs/pricing) دارد، اما [محدودیت منطقه](https://ai.google.dev/gemini-api/docs/available-regions) و شرایط استفاده از داده در سطح رایگان باید لحاظ شود؛ فعلاً هیچ دادهٔ مشتری به آن ارسال نمی‌شود.

## worker و backup رایگان

فرمان‌ها و محدودیت ابزار backup/restore در [راهنمای مستقل پشتیبان‌گیری](backup.fa.md) آمده‌اند. وجود ابزار معادل انجام backup یا موفقیت restore نیست.

[Vercel Queues](https://vercel.com/docs/queues) در مستند فعلی روی همهٔ پلن‌ها در Beta است؛ [سهمیهٔ Hobby](https://vercel.com/docs/queues/pricing) یک‌میلیون عملیات است، ولی اجرای Function سهمیهٔ جدا دارد. این گزینه برای consumer رویدادمحور بعدی قابل بررسی است؛ هنوز به این پروژه اضافه یا آزمایش نشده و worker دائمی فعال ادعا نمی‌شود. محدودیت [استفادهٔ تجاری Hobby](https://vercel.com/docs/plans/hobby) با رایگان‌بودن صف برطرف نمی‌شود.

اسکریپت `npm run backup` مسیر [pg_dump رسمی Neon](https://neon.com/docs/manage/backup-pg-dump) را آماده می‌کند: اتصال مستقیم `DATABASE_URL_UNPOOLED`، ابزار `pg_dump` هم‌نسخه یا جدیدتر از سرور، `BACKUP_ENCRYPTION_KEY` مجزای ۳۲بایتی base64 و خروجی رمز‌شدهٔ AES-256-GCM در `backups/`. کلید بیرون از Git و جدا از backup نگهداری شود؛ dump خام روی دیسک نوشته نمی‌شود. این محیط فعلاً pg_dump ندارد، backup کامل/زمان‌بندی/restore هنوز اجرا نشده است. [تاریخچهٔ Neon Free](https://neon.com/docs/postgres/backup-restore/history-window) حداکثر ۶ ساعت/۱GB است؛ جای پشتیبان مستقل و تمرین restore را نمی‌گیرد.
