# چک‌لیست اجرایی AiDirect

نسخهٔ جاری: ابزار تک‌اپراتور برای اثبات رسمی؛ محصول چندمشتری هنوز ساخته نشده است.

## آماده‌سازی مستقل از دسترسی متا

- [x] بررسی مسیر رسمی Instagram Login و Private Replies با منابع رسمی
- [x] ورود مدیر با ایمیل و رمز هش‌شده، نشست HttpOnly و بررسی Origin
- [x] تم دارک زرد، فونت فارسی محلی، نمایش موبایل و پیش‌نمایش متن پاسخ
- [x] دعوت محدود دو‌ساعته برای اتصال پیج بدون دسترسی پنل مدیریت
- [x] دیتابیس جداگانهٔ Neon با پلن رایگان
- [x] webhook با تأیید GET و امضای raw body
- [x] صف PostgreSQL، یکتایی رویداد و ارسال، قفل worker و قرنطینهٔ unknown
- [x] تطبیق فارسی، خاموش‌کردن قانون، خودی/نامرتبط/کامنت قدیمی
- [x] راهنمای عمومی، حریم خصوصی آزمایش و روند درخواست حذف
- [x] حذف دادهٔ پیج توسط مدیر با تأیید صریح و توقف ارسال‌های در انتظار
- [x] اسکریپت زمان‌بند آزمایش از کامپیوتر و endpoint احرازشدهٔ Vercel
- [x] اسکریپت بررسی رازها و CI با PostgreSQL مجزا
- [x] ۲۸ آزمون CI و ۴۵ بررسی HTTP؛ حدود اعتبار در STATUS
- [x] Push مخزن و تأیید CI روی GitHub
- [x] استقرار و بازبینی ورود در دسکتاپ/موبایل؛ گردش بصری کامل پنل با متای واقعی باقی است

## اثبات واقعی؛ وابسته به مالک اپ و پیج

- [ ] حساب Facebook/Developer سالم و اپ صحیح در دسترس باشد
- [ ] Reset کلید منتشرشده و تنظیم کلید جدید فقط در سرور
- [ ] حساب سالم Professional و public با دعوت Tester پذیرفته‌شده
- [ ] ثبت callback، ورود رسمی و فهرست‌خوانی رسانهٔ واقعی
- [ ] ارسال دستی Private Reply و مشاهده در Inbox/Requests حساب دوم
- [ ] شرایط انتشار/Advanced Access لازم برای comments webhook کامل باشد
- [ ] دریافت کامنت واقعی، ارسال خودکار و مشاهدهٔ پیام دوم
- [ ] تأیید سناریوهای نامنطبق، خاموش و تکراری در آزمون واقعی

## پیش از SaaS تجاری

- [ ] User / Workspace / Membership و دسترسی سمت سرور پس از gate واقعی
- [ ] آزمون جداسازی دادهٔ مشتری‌ها
- [ ] تکمیل مشخصات حقوقی، contact و نگهداری/حذف دادهٔ قابل اتکا
- [ ] پیاده‌سازی و آزمون callback رسمی deauthorization و data deletion
- [ ] App Review، Business Verification و Access Verification متناسب با اپ
- [ ] میزبانی مجاز تجاری و worker دائمی، پشتیبان و تمرین بازیابی
- [ ] هزینه و سقف مصرف تأییدشده؛ هیچ خریدی بدون دستور صریح

پرداخت، AI، CRM و امکانات حاشیه‌ای به نسخهٔ اثبات اضافه نمی‌شوند. برای این مرحله خرید API هوش مصنوعی لازم نیست.
