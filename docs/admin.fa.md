# پنل مدیریت و دعوت اتصال

به‌روزرسانی 2026-10-19: پنل مالک اکنون آمار سرویس و مدیریت کاربران هم دارد؛ `/admin/users` و پنل مستقل مشتری اضافه شده‌اند. [مرجع حساب‌ها و نقش‌ها](accounts.fa.md). توضیحات دعوت و اتصال پایین همچنان مخصوص proof تک‌مدیر است.

نسخهٔ 2026-10-18؛ یک مدیر و یک پیج آزمایشی، ارسال واقعی خاموش.

- `/admin`: ورود، وضعیت واقعی اتصال و رویدادها، ساخت/لغو دعوت، بررسی فقط‌خواندنی سرویس و خروج.
- `/connect/instagram`: اتصال با نشست مدیر یا دعوت معتبر.
- `/api/sendbox/connect`: شروع OAuth پس از بررسی نقش و تنظیمات سرویس.
- `/sendbox`: جزئیات و قطع اتصال؛ `/proof`: آزمایش مستقیم Meta/شبیه‌سازی.

## دعوت محدود

توکن تصادفی ۲۵۶بیتی در fragment لینک است؛ در درخواست HTTP و Referer ارسال نمی‌شود و صفحه فوراً آن را از نوار آدرس حذف می‌کند. DB فقط hash توکن و hash یک claim جدا را دارد. پذیرش اتمیک است؛ مرورگر cookie محدود HttpOnly، SameSite=Lax و روی HTTPS، Secure می‌گیرد. اعتبار دو ساعت از ساخت و یک پذیرش است. دعوت تازه، قبلی را لغو می‌کند؛ لغو، grant قبلاً پذیرفته‌شده را هم نامعتبر می‌کند. بعد از ثبت اتصال، grant فقط رسید را نشان می‌دهد و OAuth دوباره شروع نمی‌کند.

لینک را خصوصی برای صاحب پیج بفرست؛ رمز مدیر را نفرست. لینک فقط همان بار ساخت قابل کپی است، پس از refresh فقط فراداده دیده می‌شود؛ اگر گم شد، دعوت تازه بساز. صاحب دعوت اجازهٔ APIهای مدیر را ندارد.

state ده‌دقیقه‌ای به همان دعوت/مدیر و cookie مرورگر وابسته است. مالکیت حساب از API سرویس بررسی می‌شود؛ ثبت اتصال و مصرف دعوت در تراکنش است. کلید سرویس و لینک OAuth دارای کلید در API پنل یا گزارش نمایش داده نمی‌شوند. متادیتای دعوت‌های بیش از هفت روز منقضی‌شده هنگام ساخت دعوت بعدی پاک می‌شود؛ پاک‌سازی دقیق زمان‌بندی‌شده تضمین نشده است.

## بررسی

۳۸ آزمون DB جدا شامل هم‌زمانی، replay، انقضا، لغو و rollback؛ ۳۲ بررسی HTTP محلی شامل جدایی مهمان/مدیر. دعوت محلی fixture در `aidirect_test` است، نه اثبات provider. بررسی انتشار: `node --import tsx scripts/smoke-admin.mjs --create-share`؛ دعوت نهایی فقط در `.local/sendbox-owner-invite.json` ذخیره می‌شود. تست ورود Instagram یا ارسال پیام انجام نمی‌دهد.

بررسی نسخهٔ منتشرشده: ۴۳ بررسی HTTPS موفق، شامل شروع OAuth مهمان و رد callback حساب نامرتبط؛ بدون ورود Instagram یا ارسال پیام. جزئیات انتشار در STATUS.md است.
