# AiDirect — از کامنت تا گفتگو

ابزار آزمایش یک پیج Instagram با ورود رسمی متا و پاسخ خصوصی به کامنت. **اتصال و ارسال واقعی هنوز اثبات نشده‌اند.** این مخزن فعلاً SaaS چندمشتری یا محصول آمادهٔ فروش نیست.

صفحهٔ اصلی و `/sendbox` مسیر سادهٔ ورود و اتصال حساب هستند؛ جزئیات فنی Sendbox در [مستندات راه‌اندازی](docs/sendbox-setup.fa.md) می‌مانند. پنل فنی اثبات مستقیم متا/شبیه‌سازی در `/proof` با همان ورود مدیریت حفظ شده است.

## قابلیت‌های نسخهٔ آزمایش

- پنل فارسی، راست‌به‌چپ، دارک زرد و مناسب موبایل؛ ورود مدیر با ایمیل و رمز عبور هش‌شده.
- لینک دعوت یک‌بارمصرف با اعتبار دو ساعت برای اتصال پیج بدون دسترسی مدیریت.
- انتخاب پست/ریلز، کلمهٔ محرک، متن و لینک؛ پیش‌نمایش و روشن/خاموش‌کردن قانون.
- نرمال‌سازی فارسی، webhook امضاشده، صف PostgreSQL و worker با قفل و یکتایی.
- گزارش نتیجهٔ پذیرفته‌شده، شبیه‌سازی و نتیجهٔ نامعلوم؛ retry محدود برای خطاهای صریح موقت.
- حذف دادهٔ پیج توسط مدیر با تأیید صریح؛ راهنما و حریم خصوصی مخصوص آزمایش محدود.
- CI با PostgreSQL جدا و بررسی نشت مقادیر رازهای محلی پیش از push.

## شروع محلی

Node.js 24، Docker Desktop و npm لازم است. از ریشهٔ پروژه:

```powershell
npm ci
npm run setup:local
npm run login:setup
docker compose up -d
npm run db:generate
npm run db:migrate
npm run dev
```

در ترمینال دوم:

```powershell
npm run worker
```

نشانی: http://localhost:3000. مشخصات ورود فقط در فایل gitignored به نام .local/operator-login.txt ساخته می‌شوند. مقدار آن را محلی ببینید؛ رمز را در چت، عکس، گزارش یا GitHub منتشر نکنید.

برای آزمایش شبیه‌سازی، META_ADAPTER=simulated و AUTOMATION_ENABLED=true باشد؛ REAL_SEND_ENABLED=false بماند. هیچ رمز Instagram در فرم برنامه دریافت نمی‌شود.

## استقرار رایگان برای آزمایش محدود

نسخهٔ فعال: https://aidirect-kappa.vercel.app — پروژهٔ Vercel: aidirect؛ دیتابیس جدا: aidirect-test-db در Neon، پلن free_v3. جزئیات در [راهنمای استقرار](docs/deployment.fa.md) ثبت شده است. آخرین بررسی: ۲۸ آزمون CI و ۴۵ بررسی HTTP موفق، بدون ادعای اتصال واقعی متا.

وب و webhook روی Vercel اجرا می‌شوند. صف در دیتابیس پایدار است و اسکریپت زمان‌بند از کامپیوتر آزمایش‌کننده، endpoint احرازشدهٔ /api/jobs/run را صدا می‌زند. خواب/خاموشی کامپیوتر پردازش را متوقف می‌کند؛ حالت «متوقف» در پنل نمایش داده می‌شود. این روش جای worker دائمی سرویس تجاری نیست.

```powershell
npm run worker:remote
```

این فرمان فایل خصوصی .env.remote.local را می‌خواند. زمان‌بند برای کنترل مصرف، پیش‌فرض پس از دو ساعت متوقف می‌شود. هیچ Cron دقیقه‌ای در پلن Hobby پیکربندی نشده و هیچ پلن پولی خریداری نشده است.

## بررسی‌ها

```powershell
npm run typecheck
npm test
npm run build
npm run check:secrets
npm audit
```

آزمون‌های DB روی aidirect_test اجرا می‌شوند. مسیر پیش‌فرض، PostgreSQL محلی پورت 55432 است. مسیر اختیاری Neon فقط با TEST_DATABASE_URL صریح و نام دقیق aidirect_test پذیرفته می‌شود و از DB برنامه جدا است. API متا در تست‌ها mock است؛ گذشتن تست‌ها به معنی موفقیت اتصال واقعی نیست.

## رفتار و محدودیت‌ها

- این نسخه یک مدیر و یک اتصال آزمایشی دارد؛ User/Workspace/Membership بعد از gate واقعی ساخته می‌شوند.
- هر کامنت فقط یک پاسخ خصوصی؛ یکتایی در DB و قفل worker از تکرار جلوگیری می‌کنند.
- accepted یعنی متا درخواست را پذیرفته؛ دریافت یا مشاهدهٔ پیام را ثابت نمی‌کند.
- simulated هیچ ارسال واقعی ندارد. unknown ممکن است به ارسال منجر شده باشد و خودکار retry نمی‌شود.
- شناسهٔ رویداد، نتیجه و خطاهای پاک‌سازی‌شده ذخیره می‌شوند؛ متن کامنت و اطلاعات کامنت‌گذار در جدول رویداد ذخیره نمی‌شوند.
- توکن و پاسخ صف با AES-256-GCM و زمینهٔ حساب رمزنگاری می‌شوند.
- اتصال مجدد فقط کامنت‌های تازه را پردازش می‌کند؛ از بازپخش کامنت‌های قدیمی پس از حذف داده جلوگیری می‌شود.
- آخرین ۱۰۰ رسانه و ۱۰۰ کامنت خوانده می‌شوند؛ pagination کامل برای مرحلهٔ بعد باقی است.
- callback رسمی حذف داده و deauthorization، سیاست نگهداری خودکار، مشخصات حقوقی و opt-out نهایی هنوز برای انتشار تجاری کامل نشده‌اند.
